# Ben Hsieh — Personal Site

Personal portfolio site, hosted via GitHub Pages at [benhsieh-dev.github.io](https://benhsieh-dev.github.io).

## Development

This is a static site (HTML/CSS/JS, no build step), so any local server works:

**VS Code Live Server extension**
Right-click `index.html` → "Open with Live Server"

**Python (no install needed)**
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`

## Deployment

Pushes to `master` deploy automatically via GitHub Pages — changes go live within a few minutes.
